# GitHub Copilot Instructions

All project rules live in **AGENTS.md** — read it and follow it completely.

This file exists only for Copilot setups that look for `.github/copilot-instructions.md`. The preferred configuration is pointing VS Code Copilot at AGENTS.md directly (`chat.useAgentsMdFile: true`, see `vscode-settings.json.template`).

*This file intentionally contains no rules of its own. To change any rule, edit AGENTS.md only.*
