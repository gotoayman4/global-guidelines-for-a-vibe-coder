## Testing (Always Load — depth by mode)

- **Mode Sets Test Depth.** vibe: smoke per iteration + regression only when the same path bites twice or at milestone — no suite. standard: behavioral tests on critical/high-risk code, regression every fix, integration at boundaries. guarded: full pyramid + critical-flow E2E before ship. Ship boundary (ALL modes): login/payments/permissions/persistence verified by automated E2E against the deployed target, LTR and RTL. Full matrix: `speed-tiered-workflow.md`.
  → Source: `02-engineering-practices/testing-philosophy.md`
- **Behavioral Tests Only.** Tests assert inputs → outputs — never internals, spies, or call counts. standard/guarded: written first for critical features, same-iteration otherwise, never deferred past a sprint; a regression test with every fix.
  → Source: `02-engineering-practices/testing-philosophy.md`
- **No Code Without Verification + Evidence Before "Done".** Every change is unverified until exercised — "it compiled" is false; NEVER claim tests pass without running them, or present predictions as observations. Tiers: 0 trivial = lint + one line; 1 tests (standard+ default) = tests/type-check/lint/parity; 2 milestone = headless E2E on DOM/data/DB (no screenshots); 3 rare = visual, sign-off or untestable layout only. Report WHAT/HOW/RESULT + anything NOT verified. The project's `type-check` is the type verdict — an editor/language-server diagnostic is a cache, not evidence. Detail: `agent-verification-loop.md`.
  → Source: `02-engineering-practices/agent-verification-loop.md`
- **Pre-Commit + Pre-Push Gates + Two Loops + Receipts.** Hooks (husky + lint-staged): lint, type-check, format on every commit. The pre-push gate is the **declared mode's** gate: `gate:fast` + the `always` guard tier in vibe; the full pipeline `[FILL — e.g., npm run lint && npm run type-check && npm test -- --run && npm run build]` in standard/guarded. Both add the dependency-audit wrapper (a bare `npm audit` exiting 0 on an unreachable registry is forbidden) and the clean-tree check; `--no-verify` forbidden in every mode; hooks MUST NOT need real secrets. Guards declare a tier (`always` | `standard+` | `ship`) and the ship boundary runs all of them. `gate:receipt` writes `docs/gate-receipts/<UTC-stamp>.md` (strip ANSI; clean-tree informational only). A cached gate step is keyed on the content it reads and marked `cached (<key>)` in the receipt; a receipt that caches nothing prints `cached: none`. Detail: `local-ci-strategy.md`.
  → Source: `03-git-and-ci/local-ci-strategy.md`
